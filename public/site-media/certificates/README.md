# 证书图片使用说明

## 📸 证书图片位置

请将证书图片放到以下目录：
```
public/site-media/certificates/
```

- **完整路径**：`public/site-media/certificates/iso9001.jpg`

  - 证书号：46626Q00003R001
  - 认证范围：TOF 模组研发；镜头、VCSEL 芯片、VCSEL、驱动 IC、ITOF 芯片销售

- **证书信息**：

## 📝 操作步骤

### 方法一：直接复制图片
1. 将证书图片保存到电脑
2. 复制到 `public/site-media/certificates/` 目录
3. 重命名为对应的文件名

### 方法二：使用截图
1. 对证书进行拍照或截图
2. 保存为 JPG 或 PNG 格式
3. 放到上述目录

## 💡 图片建议

### 格式
- ✅ JPG：照片类证书（推荐）
- ✅ PNG：扫描件或需要透明背景
- ❌ 不支持：WebP、GIF

### 质量
- 分辨率：建议 1200x1600 或更高
- 文件大小：< 2MB
- 清晰度：文字清晰可读

### 拍摄技巧
- 光线充足，避免反光
- 正对证书拍摄，避免倾斜
- 四角完整，边框清晰

## 🔧 如果图片不显示

### 检查清单
1. ✅ 文件名是否正确
2. ✅ 路径是否正确（`public/site-media/certificates/`）
3. ✅ 文件扩展名是否正确（.jpg 或 .png）
4. ✅ 重新运行 `npm run dev`

### 调试方法
1. 打开浏览器开发者工具（F12）
2. 查看 Console 是否有图片加载错误
3. 检查 Network 标签页图片请求状态

## 🚀 添加更多证书

如需添加更多证书，在 `AboutPage.tsx` 中复制证书卡片代码，修改：
1. 图片路径
2. 证书名称
3. 证书信息
4. 图标

## 📞 遇到问题？

如果图片无法显示，请检查：
1. 图片是否在正确的目录
2. 文件名是否匹配
3. 浏览器缓存（Ctrl + F5 强制刷新）
